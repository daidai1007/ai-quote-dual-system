# Database

`migrations/` 保存 PostgreSQL 增量结构和函数脚本，不包含真实材料价格、附件价格、客户历史、经验价格或图纸数据。

建议执行方式：

```powershell
psql -v ON_ERROR_STOP=1 -U postgres -h 127.0.0.1 -p 5432 -d ai_quote_dev -f .\database\migrations\<文件名>.sql
```

注意：这些脚本来源于持续演进中的业务库，部分迁移依赖前置表。请按文件内依赖关系执行，并使用自己的脱敏种子数据。公开仓库不会自动迁移或覆盖生产数据库。

两套报价体系应保持独立：

- 公式法：重量、材料、辅材、人工、附件、喷塑和管理费由数据库函数计算。
- 快速报价：只读取经验价格库；未匹配时返回“待补充经验值”，不能静默返回 0。
