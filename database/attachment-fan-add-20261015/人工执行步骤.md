# 新增风机 SG22060HA2/220V（国产）

1. 在 Neon 控制台先确认 SQL Editor 连接的是线上目标数据库，并保留数据库恢复点；随后打开 `01-add-sg22060ha2.sql` 的全部内容。
2. 一次性执行整个文件，不要拆分。脚本会检查只有一个活动附件目录，并拒绝重复的型号、目录、成本规则或绑定。
3. 脚本会新增：`calc.attachment_price` 面价 120、`calc.attachment_classification` 分类、`calc.attachment_cost_rule` 固定成本 70，以及两者的绑定；失败会回滚事务。
4. 执行结果应返回一行：`风机 | 风机SG22060HA2/220V | 风机SG22060HA2/220V（国产） | 120 | 120 | 个 | FIXED | 70`。
5. 刷新客户端附件目录；客户端源码已加入该型号选项和 `SG` 型号匹配。现有 EXE 需要下次构建后才显示新增选项。
