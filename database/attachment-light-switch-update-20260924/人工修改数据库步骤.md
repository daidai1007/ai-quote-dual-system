# 照明灯/行程开关数据人工修改步骤

1. 先连接目标 PostgreSQL 数据库，执行下面的只读检查，确认只有一个 `ACTIVE` 附件目录版本，并记录旧“灯开关”行：

   ```sql
   SELECT data_version,status FROM calc.attachment_catalog_version WHERE status='ACTIVE';
   SELECT p.attachment_price_id,p.data_version,p.item_name,p.model_code,p.is_active
   FROM calc.attachment_price p
   JOIN calc.attachment_classification c USING(attachment_price_id)
   WHERE c.category_level1='灯开关';
   ```

2. 在 `psql` 中开启停错模式，执行脚本：

   ```text
   \set ON_ERROR_STOP on
   \i 'database/attachment-light-switch-update-20260924/01-replace-light-switch.sql'
   ```

3. 脚本会在单个事务内：停用旧“灯开关”价格行、删除其分类关系，再新增3条“照明灯/行程开关”目录、面价50元、固定成本27.56/34.06/40.06元以及规则绑定。旧价格主行如已被历史报价引用则保留为非活动行，避免破坏历史数据。

4. 执行后复核：

   ```sql
   SELECT c.category_level1,p.item_name,p.model_code,p.quick_face_price,p.unit,r.method,r.fixed_cost
   FROM calc.attachment_price p
   JOIN calc.attachment_classification c USING(attachment_price_id)
   JOIN calc.attachment_cost_rule_binding b USING(attachment_price_id)
   JOIN calc.attachment_cost_rule r USING(rule_id)
   WHERE p.is_active AND c.category_level1='照明灯/行程开关'
   ORDER BY p.model_code;
   SELECT count(*) FROM calc.attachment_classification WHERE category_level1='灯开关';
   ```

5. 正常结果应为3条新数据，第二个查询为0。任何校验不通过时脚本会自动回滚；不要手工删除 `attachment_selection` 或任何历史报价记录。
