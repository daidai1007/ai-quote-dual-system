# 照明灯/行程开关数据人工修改步骤

1. 备份目标 PostgreSQL 数据库，并确认附件目录只有一个活动版本：
   ```sql
   SELECT data_version,status FROM calc.attachment_catalog_version WHERE status='ACTIVE';
   SELECT c.category_level1,p.item_name,p.model_code,p.quick_face_price,p.unit,p.is_active
   FROM calc.attachment_price p JOIN calc.attachment_classification c USING(attachment_price_id)
   WHERE c.category_level1 IN ('灯开关','照明灯/行程开关');
   ```
2. 在 Neon SQL Editor 中新建查询页，复制 `01-replace-light-switch.sql` 的全部内容并点击 Run；不要输入 `\set` 或 `\i`。
3. 脚本在一个事务内停用该分类旧价格、移除旧分类关系，并写入5条新目录、5条固定成本规则和5条绑定；历史价格主行不会物理删除。
4. 复核结果：
   ```sql
   SELECT c.category_level1,p.item_name,p.model_code,p.quick_face_price,p.unit,r.fixed_cost
   FROM calc.attachment_price p
   JOIN calc.attachment_classification c USING(attachment_price_id)
   JOIN calc.attachment_cost_rule_binding b USING(attachment_price_id)
   JOIN calc.attachment_cost_rule r USING(rule_id)
   WHERE p.is_active AND c.category_level1='照明灯/行程开关'
   ORDER BY p.source_row_no;
   ```
   正常应返回5行：面价均为25元、单位均为“个”，固定成本与需求表一致。
5. 若执行中任一校验失败，事务会自动回滚；不要删除历史报价或 `attachment_selection`。若需要主动放弃未提交事务，执行 `ROLLBACK;`。
