### 计算与参数

仅完整名称宽度、高度、深度自动取得产品尺寸。其余实际出现的尺寸名称均为每条选择独立的人工参数，不能按子串替换或默认为0。

参数单位：尺寸 mm，密度 g/cm³，重量 kg，材料单价 元/kg，喷塑面积 m²，喷塑单价 元/m²。金属重量公式已含密度及 `0.000001` 换算，不再重复乘密度。第49行已按确认式修正；其重量不再需要“通风顶罩”变量，喷塑面积仍需人工“通风顶罩高度”。玻璃门按源表 N41/N50 的面积×55表达式计算材料成本，记录重量不适用，未虚构金属重量。

材质适用使用 `attachment_cost_rule_material`，共9条关系（3个SECC规则各1条，3个不锈钢规则各覆盖SUS304及SUS316）。`model_code`保留原文，`model_semantics`区分MODEL/MATERIAL/DESCRIPTION，未将产品列和型号列合并。

选择规则先过滤当前产品和材质适用范围，再使用当前产品专用规则优先于产品通用规则。同级适用规则重叠仍报错，不随便取第一条。已存在产品适用规则但缺少材质或未覆盖当前材质时，报ERROR，不作QUICK_ONLY。两参数的旧V2解析调用遇到材质规则会报错，后续调用必须使用 `resolve_attachment_cost_rule(附件ID,产品代码,材质代码)`；保存触发器从报价行环境快照读取材质并核对所选规则。

辅材金额和辅材清单整体原文分别保存；不拆分BOM。动态单位成本仅为材料、喷塑、辅材、人工之和。固定单位成本直接使用源值。源公式内部的2件/4件/8件与用户数量分开。

安全解析器只接受数字、完整变量、括号、加减乘除、幂及明确支持的 MIN/MAX/ABS/ROUND；拒绝属性访问、任意函数、代码片段、非法字符和非有限结果。没有不受限制的 eval、Function 或动态SQL执行公式。

服务端模块的环境参数将来须由报价服务从数据库有效材料/喷塑价格和所属产品取得，不能直接采用客户端密度/价格。**当前尚未接入该环境取价路径，报价日期有效期联调待后续API阶段进行**。

### 不停机兼容与锁等待

采用“先扩展结构、再升级API/客户端、最后切目录”。旧API继续读取旧目录到切换前。新API必须支持按ID选择、一个attachments数组、quote_line_id归属、V2视图、服务器计算和快照；不接受客户端最终金额。旧客户端必须在新目录切换前被版本门槛拦截或由已测试的兼容层处理；不能把新目录交给旧按名称匹配接口。

迁移的ALTER TABLE需要短暂强锁，时长依目标表大小、约束扫描和并发事务而定。切换使用目录写锁和单事务更新，普通读事务可继续看到旧版本，但目录写入可能短暂等待。长事务可能造成5秒锁超时，此时全事务回滚，不留半导入。与旧请求并发切换时，已选旧目录ID必须可继续按旧版本保存，不得因is_active变化回退到同名新附件。

旧目录只改活动标志，不删除；旧分类关系及引用均保留。没有TRUNCATE CASCADE、历史清空、备份表或BOM分项表。本轮不覆盖旧聚合/双报价函数，避免间接改变并柜规则。
