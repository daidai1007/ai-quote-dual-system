# 任务 B：经验价格按宽度、周长、外表面积选取参考记录

本目录提供检查与回滚脚本。尚未执行到线上；由“总修改”统一安排数据库、Render API 和客户端的配套更新。

## 匹配规则

继续使用现有产品、材质、系列、有效日期、启用状态和指定型号等约束；精确尺寸与人工指定型号保留原行为。需要按尺寸选取经验记录时，依次比较：

1. 宽度差绝对值。
2. 原周长差绝对值。程序以 `宽+高+深` 比较，与两边同时乘原有周长倍数的排序一致。
3. 箱体外表面积差绝对值，双方均使用 `2×(宽×高+宽×深+高×深)`，尺寸单位 mm，面积单位 mm²。
4. 前三项仍相同时，沿用原三维距离及规则编号、来源行、日期等稳定排序；原有精确重复冲突检查保留。

面积只用于选择参考记录，不替换原价格、重量或喷涂计算公式。现有周长比例、台数、折扣、舍入、管理费和运费算法保持不变。不批量重算已保存报价；新计算采用新规则，历史版本继续使用保存的结果。

覆盖快速报价、柜体材料经验重量、辅材经验成本、喷塑经验成本、人工经验成本。公式型成本仍执行各自原公式；附件的指定型号、人工改价和既定选取规则保持原行为。

## 回滚

回滚时在同一维护窗口暂停新计算，协调恢复原 API / 客户端，并执行：

```powershell
psql -X -v ON_ERROR_STOP=1 -f database/experience-dimension-match-20261028/03-rollback.sql
```

脚本核对已安装函数的定义指纹后恢复迁移前完整定义、删除本次备份记录并移除排序函数。保留空的技术备份表。若函数已有后续修复，则拒绝自动覆盖，需要人工合并；不得使用 CASCADE 或强制覆盖后续修改。
