# JM 公式法人工更新：线上数据库人工步骤

本次只更新公式法报价的 JM 人工目录。快速报价、材料规则、喷塑、辅材、附件、管理费率、API 地址和访问密钥均不修改。

目标公式：

- SECC：`人工 = 197.2715 + 1.423229 × 计价材料重量`
- SUS304/SUS316：`人工 = 292.5932 + 2.756249 ×（计价材料重量 - 安装板计价重量）`

数据库变更采用新目录版本 `cabinet-labor-01249192a2981dc7-v2`。脚本复制当前 57 条规则，修改 JM SECC，新增 JM 不锈钢规则，核对总数 58 条后一次性切换活动版本；原版本保留为 `RETIRED`，便于回滚。

## 操作步骤

1. 打开 Neon 的 production / Primary / `neondb`，确认角色为有权修改 `calc` 架构的角色。若页面显示已有事务，先执行 `ROLLBACK;`，再开始本次操作。
2. 完整执行 `00-readonly-preflight.sql`。预期活动版本为 `cabinet-labor-a3d12580527a3eb6-v1`，活动规则 57 条，JM 只有一条 SECC 规则。任一结果不同都停止，不执行修改脚本。
3. 完整执行 `../migrations/update_jm_labor_billable_weight.sql`。不要只选中部分语句；页面应显示事务成功提交且无 `ERROR`。
4. 完整执行 `02-readonly-verify.sql`。唯一合格结果是四个布尔检查均为 `true`，`result=PASS`；随后两行 JM 明细必须与上面的目标公式一致。
5. 打开云端 `/health`，确认 `ok=true`；打开 `/api/health/database`，确认 `ready=true` 且全部 `checks` 为 `true`。
6. 在客户端各运行一条 JM SECC 与 JM SUS304（或 SUS316）公式报价。SECC 的计人工重量应为全部计价材料重量；不锈钢的计人工重量应扣除安装板的计价重量。人工金额按两位小数四舍五入。

如果第 4—6 步失败，完整执行 `03-rollback.sql`，再重新运行 `00-readonly-preflight.sql`，确认活动版本恢复为 `cabinet-labor-a3d12580527a3eb6-v1`。
