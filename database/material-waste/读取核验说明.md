# 废料系数读取与最终口径

源文件：`废料系数.xlsx`，SHA-256：`08ab7f47b0e5329cd08503e9179c29bc91c7b362bb3e3c5ee10493bc39408290`。

以 `data_only=False` 读取后，`Sheet1!A1` 为“废料系数”，`Sheet1!A2` 为数值 **1.2**；没有单元格公式或合并单元格，其他工作表为空。源文件未修改。

最终业务口径：

- 柜体净材料重量＝面积 × 料厚 × 零件内部数量 × 对应材质密度。
- 柜体计价材料重量＝柜体净材料重量 × 程序输入的废料系数。
- 柜体材料成本＝柜体计价材料重量 × 报价日有效材料单价。
- 程序输入优先；未传时读取活动柜体材料数据版本的默认值 1.2。
- `材质固定=SECC` 的零件始终使用 SECC 密度和 SECC 材料单价；其他零件使用程序当前选择材质。
- 动态附件重量不乘柜体废料系数，快速报价、喷塑、辅材、人工也不乘该系数。
- 新报价保存净重、废料系数、计价重、分材质汇总和逐零件快照；历史报价不批量重算。

新柜体材料依据为 `JS,JP,JA,JE,JK,JM材料明细-面积公式.xlsx`，由 `scripts/build_cabinet_material_rules.mjs` 生成版本化规则。旧公式模板中的重量公式不再作为 API 材料成本依据；它暂时保留用于已发布客户端的显示兼容。`calc.cabinet_part_rule` 同时承载喷塑面积等规则，不能整表删除，否则旧客户端的公式模板和喷塑计算会一起失效。活动 API 改用 `calc.cabinet_material_rule` 后，旧重量结果不会参与最终材料成本。
