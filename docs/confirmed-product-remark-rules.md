# 已确认柜型备注规则（2026-10-29）

依据产品测试提取目录的06用户确认版和07核对版。本轮用户明确选择“图表补丁与已确认备注规则都处理（JM待确认规则不硬编码）”。这些规则只改变可编辑报价的自动备注，不改价格、成本、附件实际数量、人工覆盖文本及冻结历史。

- JS固定侧板不可拆、后背板可拆；JP固定侧板、后背板可拆。超宽仍保持原报价产品类型，备注结构沿用对应已确认规则。
- `installation_plate_quantity`、`installation_board_quantity`、`安装板数量`和安装板附件行的quantity可携带原始数量。仅这些数量字段的`-`、`－`、`—`表示不含安装板，去掉供货句和重复不含句。备注中的普通连接号不触发。
- 数值负数及attachment_price_sign扣减不是横线，不自动解释为不含。字段与明细冲突时显示复核提示，不改原附件或金额。
- 安装板正数按原始实际数量；未知不补1块，显示数量待确认。明确的厚度、材质及实际柜体/门板参数优先于标准模板。标准默认柜体1.5、门板2，已明确正数但没有板材参数时采用2.5镀锌模板；非标和部件类不套标准板厚。
- JM不设固定侧背板结论。AE/JA/JE/PS/JK等按明确门型、侧背板和附件配置输出，不能从常见样本猜测。
- FB非标、未知非标、改造和部件类不自动加仿威图。MNS/悬臂可保存component_list部件说明；JQ1/JQ2使用各自名称，不将样本数量2默认为已确认供货数量。
- 附件继续区分每台、并柜子柜与每组，保留名称、型号、规格、数量和原单位；风机滤网分开。底座高度及数量不套常见值。
- 门型、加工、排除项、防护、包装及交付取已有明确字段；商业付款/税/运费不从原始识别文本加入产品配置备注。没有来源的数据不创造。
- 有明确结构、板厚、数量或配/不含冲突时，编辑表格以系统复核图标、提示和辅助描述标记。提示不会进入导出备注，不新增拦截流程；操作员仍按原备注编辑方式处理。人工覆盖和只读历史不改写。

实现：新规则位于独立的`confirmed_quote_remark_rules.py`，原`quote_remark_rules.py`门型工具保持原样，避免影响既有门型备注替换。

输入来自现有保存字段、源配置以及附件快照；本轮不新增选型产品、不修改数据库结构、不重新识别所有432条原始记录，也不修改其来源文件。无需本项新增数据库迁移；报价分析合同趋势仍依赖此前交C的合同状态迁移。
